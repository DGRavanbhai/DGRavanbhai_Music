# 🎵 Telegram Music Bot

A powerful Telegram Music Bot built with Python and Pyrogram.

## 🚀 Features

- ▶️ Play Music
- ⏸ Pause Music
- ⏭ Skip Music
- 🔁 Resume Music
- 🛑 Stop Music
- 🎧 Voice Chat Support
- 🤖 Fast & Lightweight
- 🔒 Secure Environment Variables
- ☁️ Deployable on Render / Railway / VPS
- 📂 Open Source Project

---

# 📸 Preview

Telegram Bot Commands:

```bash
/start
/help
/play song name
/pause
/resume
/skip
/end
```

---

# 🛠 Requirements

- Python 3.10+
- Telegram Bot Token
- API_ID
- API_HASH

---

# 📦 Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/telegram-music-bot.git
cd telegram-music-bot
```

---

## Install Packages

```bash
pip install -r requirements.txt
```

---

# ⚙️ Environment Variables

Create `.env`

```env
API_ID=12345678
API_HASH=your_api_hash
BOT_TOKEN=your_bot_token
```

---

# ▶️ Run Bot

```bash
python main.py
```

# 🤖 Bot Commands

| Command | Description |
|---------|-------------|
| /start | Start the bot |
| /help | Show help menu |
| /play | Play music |
| /pause | Pause music |
| /resume | Resume music |
| /skip | Skip current song |
| /end | Stop music |
